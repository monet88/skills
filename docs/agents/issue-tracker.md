# Issue Tracker Configuration

## Configuration
- **Tracker**: GitHub Issues
- **Repository**: `monet88/skills`

## Policies & Practices
- **Specs & Tickets**: All specifications and implementation tickets are published as GitHub Issues in `monet88/skills`.
- **Operations**: The GitHub connector or GitHub CLI / API is preferred for issue operations (reads, updates, queries).
- **Authority**: Issue references and issue contents are the authoritative source of truth for task requirements.
- **Readiness**: Implementation-ready specifications use the `ready-for-agent` label. Agents should only implement issues marked with this label.
